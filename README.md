# Hexa Sort Free
Офлайн-клон Hexa Sort: без интернета (в манифесте нет разрешений), без рейтингов, безлимитные отмены/молоток/перемешивание.
Сборка: залить проект в GitHub-репозиторий -> Actions -> Build APK -> Artifacts (hexasort-apk).
Релизный APK (app-release.apk) подписан debug-ключом, ставится напрямую, весит ~1 МБ.
